# FamicomPlayer

패미컴과 오래된 브라운관 TV 모양의 투명 Windows 데스크톱 YouTube 위젯입니다. TurnTabler의 WPF + WebView2 재생 엔진, 로그인 브라우저, 재생목록, 자막, 오디오 출력 선택, OBS 오디오 연결 및 선택 설치형 Chrome 확장 기능을 기반으로 합니다.

밝은 회색·짙은 회색의 하드웨어 테마입니다. 본체와 TV는 정면에 가까운 모습이며 영상과 CRT 효과를 유리면의 곡선과 기울기에 맞춰 합성합니다. 확대된 본체와 TV를 배치한 기본 크기는 550×375 DIP이며 전체 크기를 50–300%로 자유롭게 조절할 수 있습니다. 주소창 배경과 테두리는 투명하고, 글자와 버튼은 평소 희미하게 표시됩니다.

## 실행

`release/single-file/FamicomPlayer.exe`를 실행합니다. 이미지와 .NET 런타임을 포함한 단일 실행 파일이므로 다른 파일을 함께 복사할 필요가 없습니다. Windows 10 2004 이상 / Windows 11 x64, Microsoft Edge WebView2 Runtime이 필요합니다. 소스에서 실행할 때는 `Start-FamicomPlayer.cmd` 또는 `npm.cmd start`를 사용합니다.

## 게임팩

보관함에 YouTube 링크를 붙여 넣으면 영상 제목과 썸네일을 가져옵니다. 이름을 따로 입력할 필요가 없습니다. **커버 변경**으로 사용자 이미지를 넣거나 **기본 썸네일**로 되돌린 뒤 **저장**을 누릅니다. **넣고 재생**은 편집 내용을 저장하고 해당 영상 또는 재생목록을 재생합니다. 저장된 게임팩은 검색·선택·수정·삭제할 수 있습니다. 재생목록 게임팩의 사용자 커버는 다음 영상에서도 유지됩니다.

커버 파일은 앱 보관함에 복사하므로 원본을 옮기거나 삭제해도 유지됩니다. 인터넷이 없거나 썸네일을 가져오지 못하면 내장 커버를 표시합니다. 앱 시작 시 마지막 링크·설정·게임팩을 복원하되 자동 재생하지 않습니다.

영상이 바뀌면 게임팩 LED가 지직거리고 팩이 슬롯을 따라 수직으로 조금 올라왔다가 다시 꽂힙니다. 설정에서 탈착 애니메이션, 희미한 LED 깜빡임, 삽입 소리, CRT 필터 강도·색조·채도·따뜻한 색감, 영상 불투명도, 화면 빛 반사, 위젯 크기, 항상 위 표시를 조절합니다. 삽입 소리는 음량이 0이면 재생하지 않습니다.

정지 중에는 팩이 살짝 올라온 상태를 유지하고 재생 시 다시 들어갑니다. 슬롯 앞부분을 별도 전경으로 합성해 움직이는 팩의 아래쪽을 가립니다. 게임팩 화면은 위젯·보관함 목록·커버 편집·설정 미리보기 모두 동일한 매립 테두리와 강한 CRT 필터를 사용합니다. RGB 색 번짐, 주사선, 비네팅과 신호 흔들림은 원본 이미지에 굽지 않고 실행 중 적용합니다.

설정과 게임팩은 `%LOCALAPPDATA%/FamicomPlayerNative`에 저장합니다. `cartridges.json`과 `covers/`를 함께 백업하면 보관함을 보존할 수 있습니다. TurnTabler와 설정·브라우저 프로필·프로세스·Chrome 확장 ID가 분리되어 함께 실행할 수 있습니다.

## 브라우저와 오디오

내장 브라우저에서 로그인하면 앱의 WebView2 프로필에 유지됩니다. Chrome의 로그인·확장 설정을 공유하지 않습니다. YouTube에서 실제로 활성화된 광고 건너뛰기 버튼은 기존 엔진과 동일하게 처리합니다. YouTube 페이지 구조·로그인·네트워크 상태에 따라 영상 재생 가능 여부가 달라질 수 있습니다.

설정에서 출력 스피커·헤드폰을 선택할 수 있습니다. Windows 11에서는 **OBS로 소리 보내기 → OBS 연결 주소 복사**를 사용합니다. OBS 미디어 소스의 ‘로컬 파일’을 끄고 주소를 입력하고, 입력 형식은 `wav`, FFmpeg 옵션은 `ignore_length=1 analyzeduration=0 probesize=4096`으로 설정합니다. 기본 로컬 포트는 TurnTabler와 겹치지 않는 18744입니다. 영상 소리만 전달하며 팩 삽입 효과음은 시스템 기본 출력에서 재생합니다.

선택 설치형 Chrome 확장은 `release/FamicomPlayer-Chrome-1.0.0.zip`입니다. 압축 해제 후 `Install.cmd`에서 FamicomPlayer EXE를 선택하고 안내에 따라 확장을 로드합니다. 앱 제작 과정에서는 사용자의 Chrome에 자동 설치하지 않습니다.

## 개발과 검증

.NET 8 SDK를 사용합니다. `build.ps1`은 프로젝트 `.tools/dotnet`, 인접 TurnTabler의 `.tools/dotnet`, 시스템 SDK 순서로 찾습니다. npm 패키지 설치는 필요하지 않습니다.

```powershell
npm.cmd test
npm.cmd run test:bridge
npm.cmd run test:desktop
powershell.exe -NoProfile -ExecutionPolicy Bypass -File publish.ps1 -Test
npm.cmd run dist:chrome
```

기본 검증은 게임팩 CRUD, 재시작 후 복원, 원본 삭제 후 커버 유지, 잘못된 링크 거부, 손상된 저장 파일 백업과 리소스를 확인합니다. 브리지 테스트는 재생목록 자동 전환·중복 요청·광고·오디오 출력 복구와 Chrome 메시지 검증을 확인합니다. 데스크톱 검증은 독립 임시 프로필에서 실제 YouTube 재생, 일시정지, 이전/다음 곡, 사용자 커버 유지, 게임팩 애니메이션, 설정, 브라우저 복귀를 확인합니다. 결과와 실제 화면은 `artifacts/native/` 및 `artifacts/single-file/`에 저장됩니다. `--startup-smoke`는 시작·보관함·설정·키보드/트레이 이벤트 경로만 확인합니다.

## 이미지 에셋

본체·CRT·패드·게임팩은 연결된 Forge MCP의 `gpt_image_25_sunburst`로 다시 제작한 `native/Assets/*-v5.png`를 사용합니다. 보관함 셸·회전 음량 노브는 v4, 기본 커버는 v2 리소스입니다. 생성·편집 모두 `visibility: private`를 명시하고 결과도 private임을 확인한 뒤 실제 PNG 파일을 로컬로 내려받았습니다. 사용 중인 리소스와 `provenance-v5.json` 등의 생성 기록은 저장소에 포함하고, 중복 다운로드 원본 폴더는 제외합니다. 인증 정보나 서명 URL은 저장하지 않습니다.

색상 키 배경은 WPF 합성 시 메모리에서 투명하게 처리합니다. 하드웨어에 공통 무채색 재질 효과를 적용하고 본체·패드의 밝기 기준점을 맞춰 잔여 색조 차이를 제거합니다. 영상과 게임팩 커버의 색에는 이 재질 효과를 적용하지 않습니다. 팩 이미지는 매립된 라벨 면을 가득 채웁니다.

게임팩 CRT와 하드웨어 재질 효과는 WPF 소프트웨어 렌더링에도 적용되는 Shader Model 2.0 효과입니다. 셰이더를 수정하면 `scripts/compile-effects.ps1`로 내장 바이트코드를 갱신합니다. 데스크톱 검증은 실제 렌더 픽셀 변화, 본체·패드의 무채색과 밝기 일치, 정지 중 팩 높이 유지, 버튼·다이얼 클릭 영역, 연속 크기 조절 및 설정 재열기를 확인합니다.
